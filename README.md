# Kitty Ipsum Translator 🐾

A workshop completed as part of freeCodeCamp's **Relational Database Certification** (Advanced Bash scripting module). This workshop focuses on mastering Linux standard streams (`stdin`, `stdout`, `stderr`), file redirection, pipelines, and powerful text-processing utilities in the terminal.

## 📁 Repository Contents

- **`kitty_ipsum_1.txt` & `kitty_ipsum_2.txt`** - Source text files containing cat-themed sample paragraphs.
- **`doggy_ipsum_1.txt` & `doggy_ipsum_2.txt`** - Translated output files generated by replacing cat-related terms with dog-related terms.
- **`kitty_info.txt`** - A text file storing extracted metadata, statistics, and line/word counts gathered from the source files.
- **`translate.sh`** - The primary Bash script utilizing stream editing and regex substitution to perform translations.

## 🛠 Tech Stack & Key Concepts

- **Scripting:** Bash / Shell
- **Linux Tools & Techniques:**
  - Standard Streams & Redirection (`>`, `>>`, `<`, `2>`)
  - Command Pipelines (`|`)
  - Pattern matching and text search using `grep`
  - Stream editing and string substitution using `sed`
  - Line, word, and character counting using `wc`
